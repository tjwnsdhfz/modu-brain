# 공개 기록 가져오기 안정성 개선

## 문제와 수정
- 네트워크 또는 본문 스트림이 멈추면 공개 가져오기가 무기한 대기할 수 있었다. 60초 제한과 정리되는 abort 리스너를 추가했다.
- JSON null 오류 응답은 TypeError 대신 사용자에게 구조화된 실패 코드·상태로 전달한다.
- 의도적인 취소와 네트워크 실패를 구분하고 자동 재전송하지 않는다.

## 검증
npm run check 통과: lint, 351개 테스트, coverage, 운영 스크립트 문법·마이그레이션 정적 검사, 타입 검사·Worker/클라이언트 빌드. 스톨 본문 timeout 및 null 오류 회귀 검사 추가.

## 남은 실사용 검증
운영 Supabase 인증·RLS 정책 실행, 실제 팀 기록 품질, 서버 timeout 이후 작업 중단 여부, 공유 만료와 여러 사용자 동시 사용을 운영 환경에서 확인해야 한다. DB 정적 검사는 실제 DB 통합 검사를 대신하지 않는다.


## 의존성 검사
Cloudflare 플러그인·Wrangler 및 잠금 파일 갱신 후 npm audit 0건(2026-09-22). 업데이트 후 npm run check 재통과: 351개 테스트, 줄 커버리지 87.16%. Vite의 향후 native config 로더 관련 경고는 남아 있으며 현재 빌드는 통과했다.
