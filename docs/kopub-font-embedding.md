# KoPubWorld 돋움 웹 적용 상태

## 현재 적용

- CSS family: `KoPub World Dotum`
- 로컬 우선 이름: `KoPubWorldDotum_Pro Light`, `KoPubWorldDotum_Pro Medium`, `KoPubWorldDotum_Pro Bold`
- fallback: `Apple SD Gothic Neo`, `Malgun Gothic`, `Noto Sans KR`, system sans-serif
- 승인 전 공개 배포에는 폰트 바이너리를 포함하지 않는다.

## 공개 웹폰트 임베딩 조건

한국출판인회의는 서버 탑재 후 웹서비스 또는 프로그램에서 사용하는 임베딩을 별도 승인 대상으로 안내한다. WOFF2 변환·서브셋·KoPubWorld 명칭 유지 여부도 승인 요청에 포함해야 한다.

- 공식 안내: https://www.kopus.org/biz-electronic-font2/
- 사용 등록: https://forms.gle/aQU7b3EoaF53zMKaA
- 공식 라이선스: https://www.kopus.org/wp-content/uploads/2021/04/%EC%84%9C%EC%B2%B4_%EB%9D%BC%EC%9D%B4%EC%84%A0%EC%8A%A4.pdf
- 문의: `kopus@kopus.org`, `02-3142-2334`

승인 이메일을 확보한 뒤 승인 범위에 맞는 Light 300, Medium 500, Bold 700 WOFF2 파일과 라이선스 고지를 추가한다.
