# Read-only share override

이 문서는 `/share`와 온보딩 공유 패널에서 `../MASTER.md`보다 우선한다.

## 목표

- 새 팀원이 이메일이나 원문 전체를 보지 않고 현재 맥락을 빠르게 파악한다.
- 무엇이 확정됐고 무엇이 아직 질문인지 명확히 구분한다.

## 정보 구조

1. 프로젝트 제목과 분석 시각
2. 한 문단 브리프와 핵심 맥락
3. 현재 결정과 결정 배경
4. 미결 질문
5. 참여자 관점 차이
6. 세부 온보딩 항목
7. 보조 지식맵

공유 지식맵은 브레인 캔버스의 노드 선택·검색·유형 필터·연결 상세를 유지한다. 다만 원문 ID와 전체 원문은 공유 projection에 포함하지 않으며, `근거 열기` 같은 소유자 전용 동작도 표시하지 않는다.

## 보안과 상태

- 사용자 이메일, 원문 전체, 공급자 내부정보를 표시하지 않는다.
- 만료·폐기·잘못된 토큰 상태마다 원인과 복구 경로를 제공한다.
- 공유 토큰은 URL fragment에서 읽은 뒤 API 본문으로만 전송한다.
- 오류·만료 화면에는 공개 데모와 홈으로 돌아가는 복구 CTA를 제공한다.
- 전체 화면은 warm paper 위 흰 읽기 문서처럼 보이고, 앱 대시보드 chrome을 최소화한다.
