# Landing page override

이 문서는 공개 랜딩과 `/demo` 경로에서 `../MASTER.md`보다 우선한다.

## 목표

- 첫 화면에서 “회의 요약”이 아니라 “관점 차이·미결 질문·결정 근거를 연결하는 제품”임을 이해시킨다.
- 비로그인 평가자가 한 번의 주요 액션으로 저장되지 않는 결정론적 샘플을 체험하게 한다.
- 인증은 프로젝트를 저장하거나 공유할 때만 요청한다.

## 정보 구조

1. deep indigo hero와 하나의 primary CTA `내 기록 바로 정리`
2. 카카오톡 TXT · Teams JSON · Notion JSON · 일반 텍스트 지원 표시
3. 관점 차이 → 미결 질문 → 결정 배경을 보여주는 흰 맥락 카드
4. 로그인 없는 비영속 import → 정규화 → 로컬 분석
5. 기록 축적 → 맥락 분석 → 변화·공유의 3단계 흐름
6. 개요 → 지식맵 → 온보딩 요약

공개 데모의 지식맵은 샘플 분석 전체에서 관점·결정·질문·핵심어를 파생한 브레인 캔버스를 사용한다. 사용자는 로그인 없이 노드를 선택하고 연결 이유를 탐색할 수 있지만, 원문 근거 열기나 저장 동작은 노출하지 않는다.

## `/demo` 규칙

- 샘플 입력과 결과를 즉시 준비하고 데모 작업 영역으로 이동한다.
- “저장되지 않는 공개 데모”임을 화면과 접근성 트리에 명시한다.
- 로그인 CTA는 secondary로 유지한다.
- 파일은 256KB, 정규화 결과는 20,000자 한도이며 입력·결과는 DB에 쓰지 않는다.
- 공급자 선택 없이도 TXT/JSON의 대표 구조를 판별하고 사용자가 언제든 수정할 수 있게 한다.

## 금지

- 빈 대시보드 chrome을 첫 화면에 배치하지 않는다.
- AI 캐릭터, 보라·분홍 그라데이션, 근거 없는 성능 숫자를 사용하지 않는다.
- 네트워크 실패를 샘플 성공으로 대체하지 않는다.
- KoPub돋움의 임베딩 승인 없이 폰트 파일을 저장소에 복제하지 않는다.
